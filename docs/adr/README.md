# 설계 결정 기록 (ADR)

짧은 형식: 맥락 → 결정 → 결과. 번복하면 새 항목을 추가하고 이전 항목에 "대체됨"을 표시한다.

## 0001. 모델 호출은 SDK 없이 OpenAI 호환 HTTP로 (2026-11-12)
- **맥락**: Lemonade, llama-server, Ollama, LM Studio를 바꿔 끼울 수 있어야 한다(plan §4).
- **결정**: `httpx`로 `/chat/completions`, `/embeddings`만 직접 호출한다. 주소와 모델 이름은 환경변수로만 받는다.
- **결과**: 서버 교체는 `.env` 수정으로 끝난다. 서버별 확장 옵션(`chat_template_kwargs`)도 그대로 보낼 수 있다.

## 0002. 임베딩 차원은 마이그레이션 시점에 고정 (2026-11-12)
- **맥락**: pgvector 컬럼은 `vector(N)`으로 차원이 고정되고, HNSW 인덱스도 차원에 묶인다.
- **결정**: `EMBED_DIM`으로 마이그레이션을 만든다. 청크마다 `embed_model`을 저장해 모델이 바뀌면 다음 가져오기에서 자동 재임베딩한다. 검색은 현재 모델로 만든 청크만 대상으로 한다.
- **결과**: 같은 차원의 모델 교체는 재인덱싱만, 다른 차원은 새 마이그레이션이 필요하다. 응답 차원이 다르면 명확한 오류를 낸다.

## 0003. 오프라인 해시 임베더 (2026-11-12)
- **맥락**: 테스트와 데모가 모델 서버 없이 돌아야 한다.
- **결정**: 단어와 한글 바이그램을 해시해 만드는 결정적 임베더를 `EMBED_PROVIDER=hash`로 제공한다.
- **결과**: 의미 검색이 아니라 어휘 검색이다. 실제 임베딩 모델과 비교할 기준선으로도 쓴다.

## 0004. 추론(thinking) 비활성화는 `chat_template_kwargs`로 (2026-11-12)
- **맥락**: Qwen3.5-9B는 프롬프트의 `/no_think`를 무시하고 추론을 계속했다. 한 문장 답에 68초가 걸렸다.
- **결정**: 요청 본문에 `chat_template_kwargs: {"enable_thinking": false}`를 보낸다.
- **결과**: 같은 질문이 2.7초로 줄었다. 응답에 남은 `<think>` 블록은 계속 제거한다.

## 0005. journal 가져오기는 Phase 3 전까지 코드에서 거부 (2026-11-12)
- **맥락**: 일기는 별도 스키마와 DB 권한으로 격리해야 한다(plan §12).
- **결정**: 그 격리가 생기기 전에는 가져오기 함수와 API가 `journal`을 거부한다.
- **결과**: 실수로 일기를 공용 테이블에 넣는 경로가 없다.

## 0006. 노트 폴더는 읽기 전용으로 마운트 (2026-11-12)
- **맥락**: 원본은 수정, 이동, 삭제하지 않는다(plan §8).
- **결정**: Docker에서 노트 폴더를 `:ro`로 마운트한다. 가져오기는 숨김 경로와 폴더 밖을 가리키는 심볼릭 링크를 건너뛴다.
- **결과**: 코드 버그가 있어도 원본을 바꿀 수 없다.
